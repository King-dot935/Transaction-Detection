# 部署与访问方式

项目支持云平台、打包程序和本地运行三种方式。云上版本默认只读，完整写操作需要在本地或受控环境运行。

## 一、方案对比

| 方案 | 数据库运行位置 | 成本 | 适用场景 |
|---|---|---|---|
| 云平台部署 | 云容器文件系统 | 免费档可用 | 在线查看只读 Demo |
| 打包为 Windows 程序 | 使用者本机 | 免费 | 离线展示 |
| 本地运行 | 开发者本机 | 免费 | 完整功能验收与处置链路演示 |

## 二、云平台部署

项目包含：

- `Dockerfile`：Python 3.12 slim 镜像；
- `render.yaml`：Render 部署配置；
- `requirements.txt`：运行主程序所需的依赖说明；
- `.dockerignore`：排除本地数据库和运行产物。

部署步骤：

1. 将项目仓库推送到 GitHub；
2. 在 Render 创建 Blueprint 并选择该仓库；
3. Render 根据 `render.yaml` 构建并分配访问地址。

默认环境变量：

```text
READONLY=1
SEED=1
PORT=8080
```

`SEED=1` 会在空数据库中写入演示数据。`READONLY=1` 会让所有 POST 返回 403，因此云上版本只能查看会话、规则和只读指标，不能提交反馈、自主判定或人工裁决。

部署后检查：

```powershell
curl.exe https://your-domain.example/healthz
```

预期返回 `{"ok": true, ...}`。

### 免费实例限制

| 限制 | 影响 | 处理方式 |
|---|---|---|
| 长时间无访问会休眠 | 首次打开等待冷启动 | 访问前先请求 `/healthz` |
| 文件系统不持久 | 重新部署后数据库重置 | 保持 `SEED=1` 自动灌入演示数据 |
| 单实例、小内存 | 不适合压测 | 仅用于功能查看 |
| 只读模式 | 写接口不可用 | 完整链路在本地环境运行 |

需要持久化时，应使用带持久卷的付费实例，或将 SQLite 迁移到 PostgreSQL。

## 三、打包为 Windows 程序

在 Windows 环境执行：

```powershell
pip install pyinstaller
pyinstaller -F -n 商客对话监测 demo.py --add-data "data;data" --add-data "static;static"
```

生成的文件位于 `dist/商客对话监测.exe`。运行后会在程序目录创建 `sentinel.db`。

`demo.py` 还会加载同目录下的多个本地模块。若打包后提示缺少模块，需要根据启动日志补充 PyInstaller 的 `--hidden-import` 配置。

## 四、本地运行

```powershell
cd "path\to\shangke-dialogue-monitor"
py -3 demo.py
```

访问：

```text
http://127.0.0.1:8765/
```

本地运行可以使用完整写操作：

- 自主输入；
- 批量样本；
- 待复核裁决；
- 介入单生成；
- 反馈和缓存管理。

管理接口默认只允许本机回环地址访问。如果应用绑定到非回环地址或位于反向代理后，必须配置管理 Token：

```powershell
$env:ADMIN_TOKEN="replace-with-a-long-random-token"
py -3 demo.py
```

管理请求携带：

```text
Authorization: Bearer <ADMIN_TOKEN>
```

审核管理页右上角可以填写同一 Token。Token 只保存在当前标签页的 `sessionStorage`，关闭标签页后清除。

## 五、上线前检查

- `READONLY=1` 已按部署目的配置；
- 需要写接口时已配置高强度 `ADMIN_TOKEN`；
- 外部访问通过 HTTPS；
- 仓库没有 `.env`、`sentinel.db`、日志和真实客户数据；
- 规则和条款为项目自建内容，不包含公司原始资料；
- 数据库已备份，且 `PRAGMA integrity_check` 通过；
- 明确当前版本的单机 SQLite、进程内熔断和限流限制。
